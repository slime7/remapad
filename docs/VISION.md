# Remapad 产品愿景与边界

## 项目概述

Remapad 运行在微雪 ESP32-S3-Touch-LCD-1.69 硬件上，接收 USB 手柄输入并转换为 NS2 手柄协议经 BLE 对外提供手柄服务，通过板载 240 × 280 屏幕显示状态与管理配对。

## 系统边界与非目标

- 本项目仅为娱乐用途，实现类似功能不需要 ESP32 带有屏幕。
- 界面仅针对 240 × 280 规格的小型嵌入式屏幕，不提供通用富文本排版与通用 Web 运行时。
- 设备端不运行脚本解释引擎，全部资源与界面逻辑在构建期完成固化。
- 控制器数据面与屏幕渲染解耦，输入转发与 BLE 传输独立运行，屏幕仅承载低频状态与控制。
