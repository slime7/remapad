# 0041 — 四叶草菜单左右滑动轮播与手柄双轴交互重构

- 状态: active
- 日期: 2026-09-17
- 替代: 0029

## 背景

原有 UI 采用悬浮底栏双键加纵向长滚动页：手柄左右键绑定底栏按钮、上下键在长列表中逐项遍历并驱动页面滚动，
空间利用率低，手柄上下滑动不易准确定位。新设计把屏幕划分为上方四叶草卡片轮播区与下方三等分圆角状态栏，每页内容固定居中不溢出不滚动。

## 决策

上部分重构为可左右滑动的四叶草菜单，左右无限循环切换；下部分重构为三等分圆角状态卡片（手柄状态、主机连接与电量，优先级支持 OTA 进度和手柄提示）。方向键左右与实体肩键 L1/R1 绑定上方页面切换；方向键上下绑定当前激活页面的交互控件选择；底部状态栏中区按钮仅响应触控点击触发 HOME 功能，不参与手柄焦点遍历；弹窗开启期间阻断手柄左右切页并支持叉键退出。

## 考虑的方案

- 沿用纵向滚动列表仅更新外观（否决）：无法解决内容溢出四叶草外框的问题，且手柄在嵌入式小屏上的滚动体验不佳。
- 四叶草左右滑动轮播加固定单屏页面（采纳）：每页内容紧凑居中不滚动，左右无限滑动，方向键左右切页、上下选控件，操作意图明确且无多余重排开销。

## 影响

- 正面：左右翻页与上下选控件彻底解耦，每页固定无滚动，页面切换丝滑跟手；底部三态栏按优先级统一管理状态，中区不抢占手柄焦点；弹窗状态拦截切页并支持叉键快捷关闭。
- 影响：完全取代 ADR 0029 关于底栏两键与纵向滚动的交互约定。
