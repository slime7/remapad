# 0038 — 连接由用户发起：开机与断连静默，连接键开广播窗口

- 状态: active
- 日期: 2026-09-16
- 替代: 0031

## 背景

用户实机反馈两件事：设备上电就自动发回连广播并被主机连走，想把模拟手柄放到 2P 时总是先被认成 1P，
主机已有 1P 时也无法在握把/顺序页重新分配；PWR 长按当时是 USB 角色切换，设备侧没有一颗真机配对键那样的按键。
ADR 0031 的常态回连广播虽然不叫醒休眠主机，但它仍在设备不被请求时持续发信号，
与真机「不按键就不广播」不一致，这正是抢 1P 的直接原因。

## 决策

广播只由用户动作打开，设备不再自己发信号：

- **上电静默**：删除开机自动进入配对流程与常态回连广播。
- **断连静默**：主机睡下（链路断开）后收掉广播，不自动重连。
- **连接键**：配对页「连接」按钮与 PWR 长按 3 秒是同一个动作，取代 PWR 长按原本的 USB 角色切换。
  它打开 30 秒连接窗口：已配对身份发 0x00 回连形态（主机醒着就会连回来，停在握把/顺序页时可以把设备留给它重新分配玩家序号），
  未配对身份进配对流程发发现广播；窗口内主机连上或窗口到期即收窗。
- **唤醒键**：未连接时按手柄 HOME 开 10 秒唤醒窗口发 0x81——休眠中的主机被叫醒并自动连回来，醒着的主机直接连回来；已连接时 HOME 仍是主页键。
  这条语义长在数据面上（`ns2_adv_home_key_step()` 判按下沿），实体手柄按 HOME 与调试页注入 HOME 因此是同一个动作。
- **配新主机**保留为独立入口：断开当前主机 + 发现广播，配上自动退出。
- 切换手柄身份不再自动广播（等价新手柄上电，等用户按连接键）。
- 休眠看门狗的断开重连改用连接窗口：主机此刻就在线，回连形态足够，不该用唤醒形态把可能刚睡下的主机叫醒。

窗口有效期与形态决策收敛成 ns2_adv 的纯函数：`ns2_adv_window_open/close/active` 与
`ns2_adv_choose_mode`（形态枚举新增静默 `NS2_ADV_OFF`），由固件主机端用例钉住；UI 六态新增 advertising（连接中…）。

## 考虑的方案

- 保留常态回连广播、只把窗口做成手动：设备不被请求时仍在发信号，2P 场景依旧抢 1P
- 只在按键/触摸操作设备时才广播：设备没有「任意键开机」这类输入通路，用户会找不到连接入口
- 断开后自动重连：正是要避免的形态——设备一直发信号，主机睡下也被反复打扰
- 用主机下发的 0x03/0x01（开启唤醒广播）当连接触发器：实机日志里主机从未下发过这条命令
- PWR 长按继续切 USB 角色：角色切换在模式页与串口 mode 已有入口，按键留给连接键更贴近真机
- 唤醒窗口与连接窗口合并成一种：HOME 的语义是叫醒睡下的主机（0x81），连接键的语义是等醒着的主机连回来（0x00），形态与时长都不同

## 影响

- 实机验收：开机后主机不会自动连上来；按连接键后主机在首页、握把/顺序页与电源键唤醒后都能连回来；
  主机睡下后设备不再发任何广播；主机睡下时按调试页 HOME 能把它叫醒并自动连上；
  先按断开再按连接可以拿到新的玩家序号（2P 场景）。
- 连接入口只有连接键与手柄 HOME：用户不按就「连不上」，主机自己从待机醒来后也不会主动来连；
  屏幕状态与 PWR 长按的 3 秒提示音是唯一提示。
- PWR 长按不再是 USB 角色切换入口：角色切换保留在模式页与串口 `mode`。
- 部分取代 ADR 0031 的「常态回连广播 + 显式唤醒窗口」与 ADR 0027 的 PWR 长按入口；
  唤醒窗口本身保留，改由 HOME 打开并在到期后静默。
