# 0058 — 四叶草轮播带整页滑行与两侧露边

- 状态: active
- 日期: 2026-09-24
- 替代: 无

## 背景

上部分的四叶草此前是单卡片瞬时切换：静止画面读不出左右还有页面，切页方向只靠翻页箭头弹一下。
产品侧要的是回到旧版观感：静止时两侧各露出邻页的一条花瓣边，滑动时整条带真的划过一整页。

## 决策

上部分改成按一页步距平移的四叶草轮播带：卡片底图烘成一个步距里的周期图，在滑行范围内平铺。
页面内容按槽位摆在带上——当前页居中、左右邻页各偏一页，其余页藏在窗口外，切页时整条带按一页步距滑行。
按住拖动只在切页阈值内跟手并停在这个位移上，往回滑过抖动下限取消这次换页；滑行期间页面不收点按。
底图沿用 ui/assets/main.svg 这个名字与位置，只把画法改成一个步距里的周期图。

## 考虑的方案

- 继续瞬时切换只做小滑入（否决）：看不出页面是横向排列的，产品侧要的是整页滑过的观感。
- 按旧版把多张整卡叠着画（否决）：底图不透明时后画的卡片会盖住邻页的图案与内容，只能全用透明底图逐像素混合。
- 底图烘成一个步距的周期图平铺（采纳）：整幅不透明仍走拷贝路径，静止时两侧自然露出邻页卡边，滑到任意位移图案都连续。
- 拖动全程按手指 1:1 拖出整页（否决）：拖动每帧都要重画整个内容框，实机上代价与手感都不划算。
- 拖动到阈值定住、抬手按位移阈值或甩动方向切页（采纳）：跟手只走阈值内的一小段，阈值同时充当「松手就切页」的提示。
- 往回滑过抖动下限取消这次换页（采纳）：甩动只代表意图，手指往回抽就还原，避免误翻。

## 影响

- 正面：切页是看得见的整页横向移动，静止画面能读出左右还有页面；拖动预览的位移被阈值限住。
- 影响：轮播带底图必须与窗口底色同色、整幅不透明，且与一页步距严格对齐；改卡片形状或步距要重烘这张周期图。
- 影响：滑行与跟手每帧重画整个内容框，切页时长受实机渲染节奏限制，名义时长不宜再拉长。
- 影响：部分取代 0050 里「切页瞬时完成」那条规则，方向提示交给箭头弹一下的做法随之作废；圆角元素必须带底色那条继续有效。
