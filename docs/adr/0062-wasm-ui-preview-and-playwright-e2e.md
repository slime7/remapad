# 0062 — 屏幕 UI 的 WASM 预览与浏览器端到端用例

- 状态: active
- 日期: 2026-10-01
- 替代: 无

## 背景

UI 迁到 Slint 后回归基线只剩宿主用例，缺少浏览器交付路径与直观走查入口；需要免安装桌面环境的 Web 预览与浏览器自动化端到端测试。

## 决策

设备画面编成 wasm32 挂 Slint winit web 后端与软件渲染器，与固件共用 build-support 编译口径。
模拟状态与动作结算收进 ui/preview/preview-core.slint，控制台使用宿主 HTML 面板。
开发预览由静态服务监听界面源码：变更自动重编 dist，经 SSE 通知浏览器整页刷新，构建失败在页面浮层显示日志尾。
端到端基于 Playwright，按真指针事件驱动并断言语义快照、像素取样点与控制台读数，依赖收敛于 ui/preview。

## 考虑的方案

- 继续只用宿主用例（否决：交付路径缺少回归，预览离开桌面环境不可用）
- 控制台与设备画面同画在 canvas 位图内（否决：排版受限且不利于端到端操作）
- 整幅截图比对（否决：样式微调导致大面积无意义断言失败）

## 影响

- 提供免桌面环境的 Web 预览与 Chromium 端到端自动化回归通路。
- PC 交互预览（slint-viewer 加 scripts/ui-preview.py）退役，界面走查统一走 WASM 预览。
- 新增控件需在 preview-core.slint 补齐动作结算，并在 HTML 控制台维护对应入口。
- 端到端断言与像素取样点随页面外观维护。
