# 0001 — 采用 PocketJS 与 Vue Vapor 驱动 ESP32-S3 屏幕 UI

- 状态: active
- 日期: 2026-09-03
- 替代: 无

## 背景

传统嵌入式 UI 开发多基于 LVGL 等 C/C++ 库手写代码或复杂拖拽工具，迭代门槛高且难以享受现代前端的声明式组件、响应式状态管理和即时热重载生态；而完整嵌入 WebView 又受限于 ESP32-S3 的算力与内存。

## 决策

采用 PocketJS 架构与 Vue Vapor 响应式模型构建前后端分离工程：前端通过 WebAssembly 在 PC 浏览器实现 60 FPS 零刷机实时热重载开发，通过构建期编译将组件与 Tailwind 样式光栅化为紧凑的 .pocket 二进制包并自动同步为 C 头文件，由 ESP32-S3 固件中的微型运行时驱动渲染。

## 考虑的方案

- PocketJS + Vue Vapor：现代 JSX 响应式体验、编译期样式与字体光栅化、PC 端 WebAssembly 仿真秒级热重载、无缝打包嵌入 C 固件。
- 传统 LVGL C/C++ 原生编写：运行效率高但缺乏声明式响应式状态绑定，开发调试需频繁编译烧录固件，迭代效率低。

## 影响

- 极大提升带屏幕 ESP32-S3 项目的 UI 开发与调试效率；代价是需要维护构建期样式与字体光栅化管线，且在前端无法使用浏览器原生 DOM API。
