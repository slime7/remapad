# 0063 — MCP 按键注入服务采用固件 CLI 自持状态引擎

- 状态: active
- 日期: 2026-10-01
- 替代: 无

## 背景

MCP 按键注入服务面向自动化程序与 agent，要把按键与摇杆编排发往 NS2 主机；固件 CLI 的 key 注入是单一全局掩码加单一倒计时，撑不起多组独立按下松开。

## 决策

服务显式连接，启动不碰设备，connect 建链、disconnect 收尾；按键经固件调试 CLI 注入，MCP 自己维护按下状态表：tap 直发由固件到点自松，按住键以滚动期限看门狗续期，子集松开用全体松开加重发存活键。

## 影响

- 注入不新增设备侧输入身份（pad 保持 none），与实体手柄转发可并存，按键按位叠加。
- 键名面即固件调试注入表（内部值），无模拟扳机通道；摇杆走 stick 命令的原生私有刻度。
- 时值精度按 ±10ms 量级理解；子集松开的存活键在边界上有至多一个 dp 拍（5ms）的瞬断。
