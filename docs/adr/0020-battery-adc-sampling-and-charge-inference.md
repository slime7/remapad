# 0020 — 电池电量走 BAT_ADC 采样，充电状态按电压趋势推断

- 状态: active
- 日期: 2026-09-14
- 替代: 无

## 背景

板载 B+ 经 R3 200K / R7 100K 分压接 BAT_ADC（GPIO1，ADC1_CH0）；电量此前是占位实现，屏幕与 NS2 报告显示的都是假值。
ETA6098 的充电状态输出只驱动板上指示灯、没有引到任何 GPIO，板上也没有 VBUS 检测脚，充电与外部供电无法直接测量。

## 决策

电压侧：用 adc_oneshot 配置 ADC1_CH0（12 dB 衰减、默认位宽），eFuse 曲线拟合校准可用时按其换算毫伏、缺失时退回名义满量程；每轮过采样 16 次取平均，再做一阶低通，按 VADC × 3 还原 VBAT，由独立采样任务（250 ms 周期）持有，getter 只读缓存快照。电量侧：换算放在无 IDF 依赖的 battery_curve.c，按单节锂离子的静置电压—容量对照表分段线性插值，NS2 电量等级（0-9）按每 10% 一档折算。充电侧：只承认可测量的证据——采样电压在 4 分钟窗口内上升 20 mV 以上判为充电、下降 20 mV 以上判为放电、窗口持平保持上次结论，该标志同时用于 NS2 报告的外部供电位。

## 考虑的方案

- 原始码线性换算：省掉校准与曲线拟合，但 S3 的 ADC 出厂校准数据可用，放弃它会让读数差几十毫伏，直接影响百分比分档
- adc_continuous + DMA 连续采样：采样率与缓冲远超电量测量的需要，还要占用 DMA 通道与内部 RAM
- 把 ETA6098 的 STAT 或 VBUS 分压引到 GPIO 直接测量充电与外部供电：当前板卡没有引出，属于改板而不是固件工作
- 用 USB-Serial/JTAG 的 SOF 检测当作外部供电：只认得出枚举过的 USB 主机，墙充上没有任何 SOF，会把充电中的设备判成未接电
- 电量用空/中/满三点线性：实现更短，但 3.7-3.9 V 之间一大块容量会被压成一条直线，放电过程里电量数字几乎不动

## 影响

- 屏幕状态栏、串口 status 与 NS2 报告 0x05/0x09 的电量与电压来自同一处真实采样，不再有占位值。
- 换算与映射是纯逻辑，主机端用例可守住曲线单调性、端点钳位与等级映射，不需要真机。
- 端电压法精度有限：充电时端电压被抬高、读数偏高，百分比只应作为档位参考，不应被当成库仑计。
- 充电标志是推断值：需要趋势窗口填满才可能翻转，恒压阶段与静置状态电压持平，此时保持上次结论；
  若以后需要精确的充电与外部供电状态，必须改板把 STAT 或 VBUS 检测引到 GPIO。
