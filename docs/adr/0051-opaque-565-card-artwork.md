# 0051 — 卡片底图烘成不透明 PSM_5650 走直拷路径

- 状态: active
- 日期: 2026-09-22
- 替代: 无

## 背景

卡片底图是四叶草位图，画在一层纯色根容器之上；卡片区域又是切页、拖动这些交互的重画范围的主体，底图的绘制代价直接压在手感上。
四叶草原先烘成带透明通道的 8888 位图，每次重绘都要在设备上逐像素做 alpha 混合；它本身是一条单色实心路径加抗锯齿边缘，底色恒为根容器的那一个颜色。
渲染器对 1:1 的不透明 16 位贴图有一条直拷路径，带透明通道的位图进不去。

## 决策

卡片底图改烘成不透明 PSM_5650：SVG 里垫一层根容器色的底，位图清单里把该图声明为 565。
底图因此走渲染器的直拷路径，不再逐像素混合。

## 考虑的方案

- 保持 8888 透明位图：混合必须逐像素做，纹理内存也占一倍。
- 烘成 4444：纹理内存减半，但仍是带透明通道的混合路径，还是进不了直拷。
- 不透明 5650（采纳）：帧缓冲本来就是 565，混合结果落盘时已经量化，观感一致而代价降到直拷。
- 给渲染器加「不透明贴图」快路径：渲染器在预置归档里，改动要走上游对账与重新构建。

## 影响

- 设备上像素与 8888 混合结果一致（帧缓冲是 565，混合结果本来就是 565 量化值）；浏览器预览按 565 采样，预览颜色与实机同源。
- 底图必须保持不透明、且底色与根容器同色：改底色要同时改根容器，否则卡片区域会露出色差。
- 直拷要求 1:1 且尺寸是 2 的幂；缩放、旋转或改光栅倍率都会退回软件路径，收益随之消失。
- 位图纹理内存减半，界面包体同样减小。
- 预览与实机的读色都变成了 565 量化值，界面里画的同色元素仍是设计色，写断言时不要混用。
